# Menú virtual para cafetería

Proyecto personal para practicar desarrollo web: un menú digital con varias
páginas y diseño responsive.

## Funcionalidades
- Páginas por categoría: bebidas, postres, comidas ligeras y combos especiales
- Menú de navegación para móvil
- Validación de campos del formulario
- Página de factura

## Tecnologías
HTML5, CSS3, JavaScript

## Cómo ejecutarlo
Descarga el repositorio y abre `index.html` en el navegador.
